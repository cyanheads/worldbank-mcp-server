# worldbank-mcp-server

Global development indicators via the World Bank Open Data API.

## Data source

- **World Bank Indicators API v2** — 16,000+ development indicators for 200+ countries over 60+ years
- **Auth**: None required
- **Rate limits**: Generous, no key needed

## Why it earns its keep

Directly offsets the US-centric BLS/FRED/EIA trio with global economic data. GDP, poverty rates, education, health, trade, infrastructure — all queryable by country, year range, and indicator. Comparative country analysis is a high-frequency use case for economic/policy research.

## Target users

- Economic and policy researchers comparing countries
- Journalists and analysts needing development statistics
- Agents doing cross-country comparisons (pair with BLS for US detail + World Bank for global context)
- Education and development professionals

## Scope

- Read-only
- Indicator search and metadata
- Country/region data queries with year ranges
- Topic and source browsing
- Country metadata (income level, region, capital, coordinates)
- Aggregate indicators by region/income group
