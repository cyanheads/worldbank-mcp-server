# 0.6.2 — 2026-11-19

## Added

- **`worldbank_search_projects` `theme`, `include_themes`, and `themes`** filter by theme name at any level (OR within the array, AND with other filters) and, on request, return each project's themes as `name`, `code`, `parent`, and `percent` (null unless requested, empty where none is published). Names match case-sensitively and the two theme taxonomies spell some differently, so pass both spellings ([#91](https://github.com/cyanheads/worldbank-mcp-server/issues/91)).

## Changed

- **One 50 s deadline per tool or resource call** spans every Indicators API attempt, backoff, chained read, and wait on a shared reference load; each attempt's timeout is what the deadline leaves. Expiry is `Timeout` with `reason: "upstream_timeout"`, retryable, declared in `errors[]` on every Indicators-backed tool and both resources. Its recovery says to repeat the same call unchanged after about a minute, since the Indicators API finishes and caches a read the client abandoned ([#90](https://github.com/cyanheads/worldbank-mcp-server/issues/90), [#97](https://github.com/cyanheads/worldbank-mcp-server/issues/97), thanks [@dandibarus](https://github.com/dandibarus)!).
- **`worldbank_get_poverty` spends the same 50 s deadline** and declares `upstream_timeout`. Each `/pip` request runs as a shared load that outlives the deadline; its completed response is held 5 minutes (at most 8, failures never held), so the same call repeated is answered from it. A PIP attempt is bounded at 90 s with no retry after a timeout ([#88](https://github.com/cyanheads/worldbank-mcp-server/issues/88)).
- **World Bank Projects API calls** run under the same 50 s call deadline, replacing four 15 s attempts.
- **`worldbank_get_data` page maximum** rises from 1,000 to 4,000 observations. With clamping on, a `per_page` of 1001–4000 (or `WORLDBANK_DEFAULT_PER_PAGE` above 1000) now serves that many rows, so page N covers different rows than on 0.6.1 ([#93](https://github.com/cyanheads/worldbank-mcp-server/issues/93)).
- **`worldbank_search_indicators`** ranks a headline `<phrase>, total` series ahead of its sibling breakdown families, within a match tier and source ([#92](https://github.com/cyanheads/worldbank-mcp-server/issues/92)).
- **Tool catalog prose** is cut 43.7% across all nine tools (53,611 → 30,206 bytes; the served `tools` array 88,956 → 65,431 bytes, structure unchanged), and a test holds a 31,000-byte ceiling ([#94](https://github.com/cyanheads/worldbank-mcp-server/issues/94)).
- **`worldbank_get_poverty` `poverty_line`** description states that PIP rounds the line to two decimals.
- **`worldbank_list_countries` `countries[].id`** description says three-character code; it had said ISO2.

## Fixed

- **Country lookups in `worldbank_get_poverty` and `worldbank_search_projects`** that reach the deadline fail as `upstream_timeout` with the ISO-code workaround in the hint, not `upstream_unavailable` ([#90](https://github.com/cyanheads/worldbank-mcp-server/issues/90)).
- **`worldbank_get_data`** keeps the error of a catalog lookup for a source-scoped indicator that fails or times out, instead of reporting `indicator_not_queryable` ([#96](https://github.com/cyanheads/worldbank-mcp-server/issues/96)).
- **Indicator, topic, source, and source-organization names** are trimmed of upstream padding, and an indicator search with no matches reports `totalPages: 1` ([#95](https://github.com/cyanheads/worldbank-mcp-server/issues/95)).
