# 0.6.0 — 2026-11-03

## Added

- Publish the worldbank-guide agent skill as an MCP resource.
- **`source_id`** selects a dataset for `worldbank_get_data` and `worldbank_list_countries`, including canonical subnational entities; responses disclose the serving source when known ([#76](https://github.com/cyanheads/worldbank-mcp-server/issues/76)).
- **Poverty provenance** exposes nullable `estimateType` and `distributionType` beside `estimationType`, preserving nowcast, projection, and distribution classifications without inferred defaults ([#77](https://github.com/cyanheads/worldbank-mcp-server/issues/77)).
- **Project sectors** accept names with bare or `FY17 - ` spellings, OR across names and AND with other filters; applied filters echo normalized names ([#79](https://github.com/cyanheads/worldbank-mcp-server/issues/79)).
- **Agent Plugins** adds root `plugin.json` and `mcp.json` installation manifests.

## Changed

- **Page sizes** honor requested `per_page` up to 1,000 for data, poverty, and projects, or 300 for countries; larger positive integers clamp with requested/served sizes and a notice. Project abstracts return whole without reducing page size ([#78](https://github.com/cyanheads/worldbank-mcp-server/issues/78)).
- **Packaging** ships the guide in npm, MCPB, and Docker; bundle pruning preserves SDK runtime skill modules while removing dependency author docs and build-only files.
- **Development tooling** synchronizes framework skills, packaging validation, audit classification, and the one-day dependency age policy; Bun tooling and images move from 1.4.3 to 1.4.4.

## Fixed

- **Exhaustive pagination** validates standard-envelope page bounds in both readers, failing malformed metadata as an upstream error while preserving valid numeric strings and complete reads ([#75](https://github.com/cyanheads/worldbank-mcp-server/issues/75)).
- **Source responses** omit unestablished source IDs and report malformed JSON as a non-retried upstream failure.
- **Rendered output** preserves upstream and caller text literally through Markdown, retains project link destinations, and renders every commitment component, including nulls, zeros, and a sole component equal to the total.
- **Default page configuration** rejects non-positive or fractional `WORLDBANK_DEFAULT_PER_PAGE` values at startup.
