# 0.6.3 — 2026-11-27

## Added

- **`worldbank_search_projects`** returns five nullable fields, `borrower`, `implementingAgency`, `projectCost` (USD), `esRiskRating`, and `parentProjectId`. Use `es_risk_rating` for one or more risk codes and `parent_project_id` for projects linked to a parent ([#100](https://github.com/cyanheads/worldbank-mcp-server/issues/100)).
- **`worldbank_get_poverty`** accepts `population_share` between 0 and 1 (exclusive) to return an economy's welfare threshold in PPP dollars per person per day. Use it in place of `poverty_line` ([#101](https://github.com/cyanheads/worldbank-mcp-server/issues/101)).
- **`worldbank_get_data`** reports which explicitly requested entities have no selected `mrnev` values across all pages. If an optional country lookup fails, it identifies codes whose aliases could not be checked ([#102](https://github.com/cyanheads/worldbank-mcp-server/issues/102)).
- **`worldbank_get_data`** accepts `country` and `country_codes` for `countries`, `indicator` for `indicator_id`, and `date` for `date_range`. Duplicate aliases and alias-plus-canonical pairs fail validation ([#103](https://github.com/cyanheads/worldbank-mcp-server/issues/103)).

## Changed

- **Framework tooling and skills** sync with the updated framework, including checks on untracked files and exclusion of Vitest caches from MCP bundles.

## Fixed

- **`worldbank_get_data`** checks for overlapping observations at another frequency after a confirmed empty single-period read. If the wider check fails, it preserves the original empty result and reports the uncertainty ([#99](https://github.com/cyanheads/worldbank-mcp-server/issues/99)).
