# 0.6.1 — 2026-11-11

## Added

- **`worldbank_search_projects` `objective` and `sectors`** return each project's development objective as plain text (null when none is published) and its sub-sectors as `name`, `code`, `majorSector`, and `percent`, null on every entry of a project that publishes an all-zero split; `sector` takes `sectors[].name` values ([#81](https://github.com/cyanheads/worldbank-mcp-server/issues/81), [#86](https://github.com/cyanheads/worldbank-mcp-server/issues/86)).
- **`worldbank_list_countries` `filter`** matches every word against each entry's id and name, ignoring case, diacritics, punctuation, and word order, on the global and `source_id` listings; totals and pages count matches. A filter with no letter or digit is treated as absent ([#84](https://github.com/cyanheads/worldbank-mcp-server/issues/84)).
- **`worldbank_get_data` `dimension_value`** accepts a value's label (`China`) when no id matches. A label shared by several values fails with the new reason `ambiguous_dimension_value`; `unknown_dimension_value` lists each `id "label"` pair and `validValues` gains `values: { id, label }[]` ([#83](https://github.com/cyanheads/worldbank-mcp-server/issues/83)).
- **`appliedFilters.perPage` / `requestedPerPage`** on `worldbank_search_indicators` and `worldbank_list_sources` ([#87](https://github.com/cyanheads/worldbank-mcp-server/issues/87)).
- **`WORLDBANK_CLAMP_LIMITS`** (default `true`) serves a `per_page` above a tool's maximum at that maximum; `false` advertises each maximum in `tools/list` and rejects a larger value. The config is validated at startup, before any service initializes ([#87](https://github.com/cyanheads/worldbank-mcp-server/issues/87)).

## Changed

- **Page sizes** on `worldbank_search_indicators` (now up to 3000) and `worldbank_list_sources` (100) clamp an over-maximum `per_page`, and a larger server default, with a notice, like the other four paged tools ([#87](https://github.com/cyanheads/worldbank-mcp-server/issues/87)).
- **Plain-prose cleanup** of indicator source notes, project objectives, and abstracts is one shared rule: paragraph and list-item closers break lines, `pdo`'s named entities decode, abstracts are trimmed, and an empty one is null. It runs in linear time ([#86](https://github.com/cyanheads/worldbank-mcp-server/issues/86)).
- **`worldbank_search_projects`** examples and descriptions name `3W` and `3E` as regional codes, and describe `3A` and region `Africa` as pre-split, found only on closed and dropped operations ([#85](https://github.com/cyanheads/worldbank-mcp-server/issues/85)).
- **`worldbank_search_projects` `content[]`** separates `majorSectors` names with `; `, as the new `sectors` line does, since names such as Agriculture, Fishing and Forestry contain commas ([#81](https://github.com/cyanheads/worldbank-mcp-server/issues/81)).
- **`worldbank_get_poverty`** `reporting_level` and `welfare_type` descriptions state when an economy returns more than one row ([#82](https://github.com/cyanheads/worldbank-mcp-server/issues/82)).
- **Development tooling** synchronizes framework skills, scripts, and templates.

## Fixed

- **`worldbank_get_poverty` single-year queries** keep an economy's national estimate when that year's survey covers only urban or rural areas: the gap-filled pass runs beside the survey pass and merges at row grain. In a fully surveyed single year the gap-filled pass gets at most 10 s after the survey rows arrive; after that, or on any upstream failure of it, the call answers from the survey rows with a notice ([#82](https://github.com/cyanheads/worldbank-mcp-server/issues/82)).
- **PIP responses** with a 200 status and a body that is not JSON are a serialization error, not retried; they were retried and reported as a validation error ([#82](https://github.com/cyanheads/worldbank-mcp-server/issues/82)).
- **`sector`** matches names upstream stores with a trailing space ([#81](https://github.com/cyanheads/worldbank-mcp-server/issues/81)).
- **Dimension and country labels**: listing labels, row labels, and source-scoped country names are normalized (non-breaking spaces and whitespace runs) on success responses ([#83](https://github.com/cyanheads/worldbank-mcp-server/issues/83)).
- **Country, region, and income-level names** are trimmed on `worldbank_list_countries`, `worldbank_get_country`, and the country resource ([#84](https://github.com/cyanheads/worldbank-mcp-server/issues/84)).
- **`per_page` schema** on the four tools that already clamped no longer advertises `maximum: 9007199254740991` in `tools/list` ([#87](https://github.com/cyanheads/worldbank-mcp-server/issues/87)).
