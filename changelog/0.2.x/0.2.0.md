# 0.2.0 — 2026-08-09

## Added

- **`worldbank_get_poverty`** tool — poverty headcount ratio, poverty gap, poverty severity, and the Watts index at any poverty line, plus the Gini coefficient, mean log deviation, Wolfson polarization, and the ten decile income/consumption shares on survey-derived rows. Backed by a new `PipService` (`src/services/pip/`) wrapping the World Bank Poverty and Inequality Platform (PIP) `/pip` endpoint — a separate upstream from the Indicators v2 API the other tools read, with its own flat-array envelope, no server-side pagination, and real HTTP status codes instead of an HTTP-200 error sentinel. [#8](https://github.com/cyanheads/worldbank-mcp-server/issues/8)
- **`fill_gaps`** input (default `true`) merges PIP's survey rows with its gap-filled estimates so a query answers every requested year even where no survey exists, while keeping the real distributional data on years a survey does cover — PIP's own gap-filled mode nulls `gini`, `mld`, `polarization`, and the deciles on every row it returns, including survey years.
- **`WORLDBANK_PIP_BASE_URL`** env var (default `https://api.worldbank.org/pip/v1`), added to `.env.example`, `server.json` (both stdio and HTTP package entries), and `src/config/server-config.ts`.

## Changed

- **Server-level `instructions`** now point poverty, Gini, and decile-distribution questions at `worldbank_get_poverty` and note it takes ISO3 codes for individual economies only.
