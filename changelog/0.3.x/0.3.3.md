# 0.3.3 — 2026-09-12

## Changed

- **`worldbank_get_data`'s `countries` string now splits on commas and semicolons**, matching `worldbank_get_poverty` and `worldbank_search_projects` (#25). `"US,JP,KR"` resolves to `["US","JP","KR"]`; a value that splits to zero codes (`","`, `[","]`) is rejected the same way an empty value already was. `"all"` combined with any other code is now rejected before the request, since upstream answers that mix with the same envelope as an invalid code.

## Fixed

- **An indicator the data endpoint won't serve no longer blames the country codes** (#24). The World Bank data endpoint rejects some catalogued indicators — every WDI Database Archives ID, plus non-archive sources like PEFA and ICP — with message id `175`, distinct from the generic id `120` used for a genuinely invalid indicator or country. `worldbank_get_data` now reports these as `indicator_not_queryable`, naming the indicator's catalog source(s) when the lookup succeeds, with recovery pointing at `worldbank_search_indicators` instead of `worldbank_list_countries`.
