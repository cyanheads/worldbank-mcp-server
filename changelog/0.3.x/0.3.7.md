# 0.3.7 — 2026-09-16

## Changed

- **`createApp({ sessionMode: 'stateless' })`** — with `MCP_SESSION_MODE` unset, the server now resolves `stateless` over HTTP; it previously fell back to the schema default `auto`, which resolves to `stateful`. An explicit `MCP_SESSION_MODE` value still overrides. The Docker image and `.env.example` already set `stateless`, so those deployments are unchanged.
