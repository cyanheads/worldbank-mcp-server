# 0.3.2 — 2026-08-25

Nothing under `src/` changed — the tool surface, schemas, and runtime behavior are identical to 0.3.1. Only the published container image differs.

## Changed

- **The production `bun install` comment states what `--omit=peer` drops** and why the OpenTelemetry `bun add` below repeats the flag.

## Fixed

- **`Dockerfile` build stage pinned to the native builder platform** (`FROM --platform=$BUILDPLATFORM`). On an arm64 host the `linux/amd64` leg compiled TypeScript under QEMU, where Bun 1.4.0 aborts (exit 134); the compiled JavaScript is architecture-independent and copies into both target-platform production images. The production stage is untouched and still built per target platform.
