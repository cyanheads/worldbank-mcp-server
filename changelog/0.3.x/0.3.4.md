# 0.3.4 — 2026-09-12

## Changed

- **Tool and resource descriptions rewritten in imperative mood** ("List" not "Lists") as single string literals instead of concatenated fragments, across every tool and resource definition.

## Fixed

- **`worldbank_search_indicators` now applies `source_id` together with `topic_id`** (#28). `/topic/{id}/indicator` honors `source` the same way `/indicator` does — intersecting the two scopes and rejecting an unknown source ID — so a topic no longer silently drops a source filter.
- **`worldbank_get_country`, `worldbank_get_indicator`, and their matching resources reject `"all"` and multi-code selectors** (#29). `country_code` and `indicator_id` are pattern-validated (2–3 letters/digits; letters/digits/`.`/`_`/`-`), and a response resolving to more than one distinct ID throws `multiple_countries`/`multiple_indicators` instead of returning an arbitrary single row.
- **`worldbank_search_indicators` rejects a punctuation-only `query`** as `empty_query` instead of matching the entire catalog (#33).
- **Indicator `sourceNote` is returned as plain text** (#34). HTML line breaks become line breaks, other tags are dropped with their text kept, and entities are decoded.
- **An upstream HTTP 404 on an ID-bearing path now maps to the same typed reason as the HTTP-200 error envelope** — `indicator_not_found`, `country_not_found`, `invalid_filter` — instead of surfacing as a raw fetch failure carrying the upstream error page (#36). New identifier schemas (`src/services/worldbank/identifiers.ts`) pin ID shapes at the boundary.
- **`tests/` is now type-checked** — `tsconfig.json` covers `src/` and `tests/`; a standalone `tsconfig.build.json` extends the framework base for emit (#26).
