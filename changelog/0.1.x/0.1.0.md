# 0.1.0 — 2026-05-23

## Added

- **`worldbank_search_indicators`** — search 29,500+ WDI indicator catalog by keyword, topic, or source; handles WB API quirk where `searchterm` is silently ignored when a topic/source filter is active (client-side filtering applied in those cases)
- **`worldbank_get_indicator`** — full metadata for a known indicator ID (name, source, organization, topics); detects WB's HTTP-200 error envelope for invalid IDs
- **`worldbank_get_data`** — primary data tool; queries observations for one or more countries (ISO2/ISO3/aggregate/`all`) across a year range or most-recent-N values; reports `nullCount` for data-sparsity signaling
- **`worldbank_list_countries`** — paginated country listing with metadata; excludes aggregate entries by default (`include_aggregates=false`)
- **`worldbank_get_country`** — full country metadata by ISO2, ISO3, or aggregate code
- **`worldbank_list_topics`** — all 21 WB thematic topics with descriptions
- **`worldbank_list_sources`** — paginated list of 70+ data sources/datasets
- **`worldbank://indicator/{indicatorId}`** resource — stable URI for indicator metadata
- **`worldbank://country/{countryCode}`** resource — stable URI for country metadata
- **`WorldBankApiService`** — single service wrapping the WB Indicators API v2; `fetchWithTimeout` + `withRetry`, HTML-error-page detection, sparse-payload normalization
- **`getServerConfig()`** — lazy-parsed env config for `WORLDBANK_API_BASE_URL` and `WORLDBANK_DEFAULT_PER_PAGE`
