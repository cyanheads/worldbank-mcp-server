# 0.1.2 — 2026-05-24

## Changed

- **`worldbank_search_indicators` description** no longer exposes the client-side filtering implementation detail; replaced with a user-facing behavioral statement.
- **Dockerfile** labels: `org.opencontainers.image.title` prefixed with `@cyanheads/`, description and source labels populated.
- **`manifest.json`** description and `author.name` filled in.
- **`package.json`** `mcpName`, `bugs`, `homepage`, `author`, `funding`, `packageManager` fields added; `repository.url` in git+https form; keywords expanded.
- **`server.json`** `name` changed to `io.github.cyanheads/worldbank-mcp-server` (registry convention).
- **`bunfig.toml`** added with install and run defaults.

## Fixed

- **`list_countries`** now handles array-wrapped error envelopes (`[{message:[...]}]`) returned by the World Bank API for invalid `region` or `income_level` filter codes. Previously caused a type crash; now throws a `notFound` error with a recovery hint.
- **`list_sources`** pagination fields (`page`, `pages`, `total`) coerced from strings to numbers — the `/source` endpoint returns them as strings despite the typed envelope.
