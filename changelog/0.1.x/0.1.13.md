# 0.1.13 — 2026-06-15

## Added

- **`createApp({ instructions })`** — `src/index.ts` now ships a server-level orientation string sent on every `initialize`: the `worldbank_search_indicators` → `worldbank_get_data` workflow, dotted indicator codes (`NY.GDP.PCAP.CD`), accepted country forms (ISO2/ISO3, aggregate codes, `WLD`, `"all"`), and `worldbank_get_data` constraints (`date_range`/`mrv` mutually exclusive, null sparse cells, `"all"` paginates).

## Changed

- **Plugin display identity** — `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and `.codex-plugin/mcp.json` use the unscoped `worldbank-mcp-server` for the agent-facing fields (plugin `name`, `mcpServers` key, Codex `interface.displayName`, Codex `mcp.json` server key). Install `args` stay `@cyanheads/worldbank-mcp-server` — the published npm name is unchanged.

## Dependencies

- `@biomejs/biome` ^2.4.16 → ^2.5.0
- `vitest` ^4.1.8 → ^4.1.9
