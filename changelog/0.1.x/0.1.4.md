- **`manifest.json`** description updated to match canonical tagline; `repository`, `homepage`, and `license` fields added.
- **`server.json`** `runtimeHint` changed from `"node"` to `"bun"` on both packages entries.
- **Dockerfile** `org.opencontainers.image.description` updated to canonical tagline; label order aligned with OCI annotation conventions.
