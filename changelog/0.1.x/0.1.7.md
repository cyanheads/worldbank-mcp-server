# 0.1.7 — 2026-05-24

## Changed

- **`worldbank-search-indicators`** — missing-filter guard now throws `missing_filter` with `ValidationError` code instead of `no_match` (`NotFound`); `missing_filter` error contract declared in `errors[]`.
- **`worldbank-get-data`** — `invalid_params` error contract corrected from `InvalidParams` to `ValidationError` code (mutually exclusive fields `date_range`/`mrv` are a validation, not an RPC, error).
- **`worldbank-service`** — consolidated imports (removed orphaned `ReqCtx` declaration above import block); collapsed duplicate `clientFilterTerm` pagination guard into a single branch; removed nullish fallback on `items` (API guarantees non-null after successful parse).
- **`worldbank-get-data`** — bucket pattern for `Map` grouping (eliminates double-lookup `has` + `get` pair).
- **`@cyanheads/mcp-ts-core`** ^0.9.7 → ^0.9.9 (`@hono/node-server` ^2.0.3 → ^2.0.4; `git-wrapup` skill; `fuzzTool` Phase 1 pre-parse; `ZodArray minLength`; `fast-check` → optional peer dep; "Close the loop on issues" rule).
- **`git-wrapup` skill** added; **`release-and-publish` skill** v2.5 → v2.6.
- **CLAUDE.md** — "Close the loop on issues" rule added; `git-wrapup` listed in skills table; framework version reference updated.

## Fixed

- **`worldbank-country.resource`** and **`worldbank-indicator.resource`** — `cause: err` was passed as a field in the data object (second arg to `notFound()`) instead of the options bag (third arg). Error cause was silently dropped from the error envelope.
