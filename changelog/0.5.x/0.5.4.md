# 0.5.4 — 2026-10-18

## Changed

- **Whole-scope data reads** fetch one page at a time and retain compact observations with shared country identities and indicator metadata, preserving selection, cache checks, and response fields; memory still grows with the requested scope ([#70](https://github.com/cyanheads/worldbank-mcp-server/issues/70)).
- **Tool error severity** marks 30 input and lookup-miss reasons as `notice`; upstream failures retain error severity, and severity alone preserves response bodies and failed-call status ([#59](https://github.com/cyanheads/worldbank-mcp-server/issues/59)).
- **Development guidance** syncs the framework skill references; README and dependency badges reflect the current runtime.
- **Desktop bundles** exclude development source, tests, scripts, documentation, coverage, and editor/CI configuration.

## Fixed

- **`worldbank_get_data`** identifies verified Global Economic Monitor groups as aggregates only for source 15, without changing the global country index or inventing ISO3 codes ([#68](https://github.com/cyanheads/worldbank-mcp-server/issues/68)).
- **`worldbank_get_poverty`** routes `FCVY` and `FCVN` through PIP's fragility aggregates; rejected `FCS` calls receive `FCVY` guidance without asserting equivalent membership ([#60](https://github.com/cyanheads/worldbank-mcp-server/issues/60)).
